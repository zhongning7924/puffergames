# 愤怒河豚的弹弓 — 广告接入方案

> 结论先行：**激励视频为主（已有 3 个点位）→ 插屏补量（新增，退出关卡时）→ 底部横幅兜底（新增，只放选关页）**。
> 代码骨架已落地在 `src/ad.js` + `src/game.js` + `src/screens.js`，替换真实广告位 ID 即可生效。

---

## 一、三种广告形态对比

| 形态 | eCPM 水位 | 体验破坏 | 玩家接受度 | 本项目建议 |
|------|-----------|----------|------------|------------|
| **激励视频** | 最高（约 15–45 元） | 无（玩家主动、有奖励） | 高 | ✅ 主力，保留并做精 |
| **插屏** | 中高 | 中（强制打断，可关闭） | 中 | ✅ 补量，严格频控 |
| **原生模板（底部横幅）** | 最低 | 低但常驻占屏 | 低（易误触） | ⚠️ 只放选关页，做布局避让 |

> ⚠️ **2026 年现状**：微信小游戏后台**已不再支持新建 Banner 广告位**，需创建「**原生模板广告**」，
> 代码用 `wx.createCustomAd`（基础库 2.11.1+）。它是原生组件，**层级最高、盖在 Canvas 之上**，
> 所以必须做布局避让，否则会遮住选关页的「返回」按钮（触发诱导点击风险）。
> 代码里保留了对老基础库 `wx.createBannerAd` 的回退。

## 二、推荐点位（含频控）

### 🥇 激励视频（玩家主动，收益主力）

| # | 点位 | 触发时机 | 奖励 | 状态 |
|---|------|----------|------|------|
| R1 | **失败复活** | 失败页，本关首次失败 | +1 只河豚，原地继续 | ✅ 已有（`settle.js: watchAdRevive`） |
| R2 | **双倍积分** | 通关结算页 | 本关得分 ×2（并重算星级） | ✅ 已有（`watchAdDoubleScore`） |
| R3 | **弹道全显** | 失败页，同一关失败 ≥2 次 | 本关弹道长度拉满 + 立即重开 | ✅ 已有（`watchAdTrajectoryBoost`） |
| R4 | **珍珠关提前进入**（建议） | 选关页珍珠关入口 | 每看 1 次解锁 1 次珍珠关挑战 | 🔜 可选，收益高但削弱收集成就感 |

**为什么 R1 最重要**：失败瞬间是玩家「不甘心」情绪最强的时刻，观看率最高。R2 是顺手薅羊毛，R3 是卡关救济，
三者互斥且都只在需要时出现，不会打扰正常通关流程。

### 🥈 插屏广告（自然停顿点补量）

| 项目 | 设定 | 理由 |
|------|------|------|
| **触发时机** | 从关卡内（含结算页）点「菜单 / 返回」退出时 | 玩家的**意图已经是离开**，此时打断不伤体验 |
| **禁止时机** | 通关后点「下一关」连闯时 | 连闯是最强心流，插广告直接劝退 |
| **首启保护** | 本局前 2 次退出不弹 | 保护新手前几分钟体验 |
| **频次** | 之后每 3 次退出弹 1 次 | 留足间隔，避免"一局三广告" |
| **冷却** | 两次插屏间隔 ≥ 60 秒 | 微信会自动限流，主动冷却更稳 |
| **互斥** | 展示期间隐藏底部横幅 | 避免叠加触发审核风险 |

代码位置：`game.js` 的 `goToMenu()` / `goToLevelSelect()` → `AD.onLevelExit()`，频控在 `ad.js`。

### 🥉 原生模板（底部横幅）

| 项目 | 设定 |
|------|------|
| **展示页面** | 仅 `LEVEL_SELECT`（选关页） |
| **隐藏页面** | 战斗 READY/AIMING/FLYING/SETTLING、WIN/LOSE 结算、主菜单、排行榜、设置 |
| **尺寸** | 模板 100% 为 360×106，按屏宽等比缩放，`onResize` 回调修正后贴底 |
| **刷新** | `adIntervals: 30`（微信要求 ≥30 秒） |
| **避让** | 选关页 `viewBottom` 与「返回」按钮按 `AD.bannerInset()` 上移，绝不遮挡 |

> 主菜单为什么不放：菜单有吉祥物双击彩蛋和「开始/排行榜/设置」三个按钮，横幅会挤压布局并诱发误触。
> 结算页为什么不放：结算页已有「双倍积分」激励按钮，再叠横幅属于典型的诱导点击。

## 三、明确不要做（会掉量 / 违规）

- ❌ 通关 → 下一关 之间插广告（打断连闯，留存杀手）
- ❌ 广告按钮与操作按钮重叠（微信判定诱导点击，可关停广告位）
- ❌ 强制观看才能进游戏 / 才能玩下一关
- ❌ 一局内插屏弹超 3 次
- ❌ 用占位 ID 上线占位（加载失败虽会自动降级，但会拉低填充率与账号质量分）

## 四、接入步骤

1. **开通流量主**：公众平台 → 功能 → 流量主。满足任一条件即可（以后台显示为准）：
   - 累计独立访客 UV > 500 且无刷粉/严重违规；
   - 同主体名下已有小程序满足条件一并持续变现满 1 个季度；
   - 小游戏开通游戏圈且有有效活跃（官方贴 ≥5 篇）。
2. **创建 3 个广告位**：激励视频 / 插屏 / 原生模板（横幅），分别记录 `adUnitId`。
3. **填 ID**：改 `src/ad.js` 顶部的 `AD_UNIT`（三种 ID **不能混用**，混用会导致后台数据恒为 0）。
4. **真机验证**：开发者工具不显示真实广告，必须真机预览；重点测 `onClose` 的两种结果——
   完整看完发奖励、中途退出不发奖励。
5. **回归**：`node tools/e2e-tests.js` → `node tools/validate-levels.js` → `node build-preview.js && node verify-preview.js`。

## 六、顺带修掉的体验问题

通关结算有一段「仪式感动画」（得分滚动 → 剩豚逐只飞入 → 三星依次弹出）。
原逻辑是**动画期间任何点击都只用于跳过，不触发按钮**，玩家会以为「点了下一关没反应」，
在剩豚多的关卡最明显——第 16 关（5 只河豚的分裂教学关）动画最长可达 **5.9 秒**。

现已改为：**点在按钮上就跳过 + 立即生效；点在空白处才只跳过**（保留防误触）。

## 七、现在有收益吗？能不能直接上线？（2026-10-20 核对）

### 7.1 结论：目前收益 = 0，且不是「少赚」而是「完全没有」

| 事实 | 现状 | 后果 |
|---|---|---|
| 三个广告位 ID | 全是占位符 `adunit-0000000000000000/1/2` | 加载必失败 → 模块自动降级 → 玩家**看不到任何广告按钮** → 收益 0 |
| 流量主资格 | 未开通（需 UV>500 或游戏圈发帖 或 同主体继承） | 即使填了 ID 也拿不到真实广告 |
| 广告位是否已创建 | 未创建（流量主开通后才能建） | 没有真实 adUnitId 可填 |

> 代码里已加启动自检：只要还是占位 ID，控制台会打 `[ad] 广告位 ID 仍是占位符…` 告警，避免「以为接了、其实没收益」。

**收益怎么算**：按**广告展示次数**结算（eCPM 计价），不是按游戏流水。激励视频 eCPM 最高（文档第一章给的参考区间 15–45 元/千次），插屏中高，原生模板最低。
粗算：`收益 ≈ 展示量 × eCPM ÷ 1000`。个人主体由平台**代扣 20% 个人所得税**；结算通常在次月，满一定金额可提现。

### 7.2 能不能直接上线：游戏侧可以提审，账号侧还差 3 件事

**代码侧（本项目已就绪）**

| 项 | 状态 |
|---|---|
| 包体大小 | ✅ 约 1.1MB（src 556K + sounds 484K），远低于主包上限 |
| 隐私弹窗 | ✅ 未调用任何隐私接口（不取昵称/头像/位置），只需在 MP 后台「用户隐私保护指引」勾「承诺未处理用户任何信息」 |
| 广告降级 | ✅ 无广告/无流量主/占位 ID 下静默降级，不阻塞玩法 |
| 广告点位与频控 | ✅ 已按方案落地（R1/R2/R3 + 插屏频控 + 选关页横幅避让） |
| 域名白名单 | ✅ `https://aiclub.hk.cn` 已在 request 合法域名中（真机 `POST /v1/login` 返 200 可证） |

**账号侧（只能在公众平台操作，代码改不了）**

1. **小程序备案**（工信部）：未备案时**提审按钮是灰的**。入口在 MP 后台，周期约 7–20 天，建议立刻提。
2. **类目**：服务类目必须选「游戏 → 休闲/益智」等无前置审批类目。个人主体不能碰虚拟支付（内购）。
3. **软著 / 承诺书**：休闲类目下个人主体通常可用承诺书替代软著；企业主体多要求软著。
4. **版号**：纯广告变现（IAA）**不需要版号**；一旦做内购就必须有版号，且版号申请主体只能是企业。

**顺序建议**：备案与开发并行 → 类目/资质 → 提审上线（此时还没广告收益）→ 攒够 UV 或开游戏圈发 5 帖 → 次日刷新开通流量主 → 建 3 个广告位 → 填 `AD_UNIT` → 真机验一遍 → 再发版。

### 7.3 上线前必须真机验证的 3 件事

1. **激励视频 `isEnded` 两种结果**：看完发奖励；中途退出**不发**奖励（开发者工具不显示真实广告，必须真机）。
2. **插屏频控**：本局前 2 次退出不弹、之后每 3 次弹 1 次、间隔 ≥60 秒；连闯「下一关」绝不能弹。
3. **原生模板横幅避让**：选关页底部与「返回」按钮不能被盖住（这是诱导点击风控点）。
