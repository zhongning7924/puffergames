# 难度曲线重构方案（冲吧！小河豚）

> **For agentic workers:** 用 superpowers:subagent-driven-development 或 executing-plans 分批执行；每批必须跑通回归门（红不提交）。

## Context（为什么改）

玩家反馈：不管章王关还是普通关，**布局策略有问题、没有难度递增、每关都容易过**。白盒数据（40 关鸟/猪/材料统计）定位根因——愤怒的小鸟靠三道压力逼玩家，本作全卸了：

1. **资源过剩**：普通关 鸟/醒猪 ≈ 1.0~1.5，章王关 2.0~2.5（鸟比猪多）。愤怒的小鸟后期鸟/猪 **<1**，逼"一鸟多用"。
2. **砰砰万能**：爆炸半径 110（近 1/3 屏宽），一发同时**范围清猪 + 碎石(stone×2) + 推倒 reach≈149**；且 L5 入手后每关都能带，废掉兵种克制与精确瞄准。
3. **材料太脆、克制失效**：ice hp1、wood hp2——用不对鸟也一碰就碎，dash 克木/split 克冰的 ×2 矩阵形同虚设；stone hp4 但砰砰爆炸对石 ×2 照样秒。
3b. **材料只有三种、normal 嘟嘟无主场**：dash 克木、split 克冰、bomb 克石，唯独无技能的嘟嘟没有专属克制对象。**新增第四材料「火/熔岩砖」，由嘟嘟铁头重击克制（×2）**，四鸟各有主场。
4. **猪裸奔**：普通猪 hp1~3、按体型(radius)给血，大多裸露坐柱顶，无"先破防再杀猪"。
5. **布局同质**：35 个普通关是模板化"柱+梁+猪"，材料平均撒（木3/冰3/石3），无章节主材、无机制递进课。

**已确认的取舍**（用户拍板）：
- 砰砰：**不改爆炸机制**，靠「配队稀有化 + 石头加厚到非砰砰打不动」。
- 猪防护：**不新增戴盔猪类型**，靠「石/冰壳包裹 + 大块头高血量猪」。
- 节奏：**分章节小步交付**，每批跑通即可玩、可提交。

**目标**：建立单调递增的难度曲线，让"省弹药、选对鸟、找承重"三道压力回归；**红线是每关必可通关（永不死局）**。

## 目标难度曲线

| 章节（关） | 鸟/醒猪比 | 主材(占比≥65%) | 砰砰配队 | 猪防护 | 机制/几何课 |
|---|---|---|---|---|---|
| 一·新手湾 L1-8 | 1.3~1.5 | 木 | L5 起 1 只(教学) | 裸猪/坐木堆 | 直射、打基座让木堆倒 |
| 二·珊瑚海 L9-16 | 1.0~1.2 | 木→冰(L13起冰主) | ≤1 | 木/冰壳内、有顶 | 高抛(挡平射)、split 散弹清冰排 |
| 三·深渊要塞 L17-24 | 0.85~1.0 | 冰(split主场)+少量石 | 0~1 | 冰壳包裹 + 中猪(hp2) | 打承重厚冰柱、双结构分兵 |
| 四·极境深渊 L25-32 | 0.75~0.9 | 石(bomb主场)，L31 起零星火砖预告 | 1~2(石量>乱炸容量) | 石壳包裹 + 中/大猪(hp2~3) | 炸石地基、窄弹道窗口 |
| 五·潮汐王座 L33-40 | 0.6~0.8 | 重石 + **火(熔岩)复合**，火砖占 ~30% | 1~2 | 深埋石/火堡 + 大猪 | 石靠砰砰、火砖抗炸只吃嘟嘟铁头精准点杀、坍塌触发冻果分段链 |

- **章王关 L8/16/24/32/40**：T6/T8/T9 布局原则不动；只随全局材料提血复验，标准是「最优解用鸟数 ≥ 配置鸟数−1」（几乎不浪费），且 boss-sim 必 WIN。
- 普通关每关冻果 **0~2 颗**、埋结构内（要坍塌压爆/精确引爆），作效率奖励而非清场主力。

## 工作线

### W1 — 全局数值拧紧（`src/config.js`）
材料血量拉开，让克制矩阵真正生效（`Block.takeDamage` 公式：`health -= floor(force*mult/4)`）：

| 材料 | hp 旧→新 | 密度 | 验证（撞力 ~10~14） |
|---|---|---|---|
| wood | 2→**3** | 1.0 | dash(×2) 稳碎；normal(×1) 需狠撞、弱撞不碎 → dash 断木高效 |
| ice | 1→**2** | 0.5 | split 丸子(×2) 一发三碎三块；normal 一发一块 → split 清冰排效率×3 |
| stone | 4→**6** | 2.0 | bomb 爆炸(×2) 近心碎；dash(×0.6)/split(×0.5) 一次 ~1 点=刮痧；normal 需 2 次狠撞 → **石头基本只靠砰砰** |
| **fire（新·熔岩砖）** | —→**5** | 1.5 | **normal 嘟嘟(×2)** 高速直撞力~12×2=24→floor(24/4)=6 一发碎；**bomb(×1.0) 近炸** 14→3 点一发不碎（熔岩抗爆）；dash(×0.6)/split(×0.6) 刮痧 → **火砖只吃嘟嘟铁头精准点杀** |
| burst | 1 | 0.8 | 不变 |

- **克制矩阵补 fire 列**（`BIRD_TYPES.damageVs`）：normal `fire:2.0`、bomb `fire:1.0`、dash `fire:0.6`、split `fire:0.6`。四鸟各有主场：dash 木 / split 冰 / bomb 石 / **嘟嘟 火**。
- **火砖视觉**（`src/entities.js` `Block.draw` 加 `type==='fire'` 分支）：熔岩深红 body + 发光橙裂纹 + 亮边；`config.js` `COLORS` 加 fire 配色、`BLOCK_TYPES.fire`。火砖与木冰石同走坍塌/爆炸/连锁，无额外环境机制（纯第四材料）。
- 猪：**不改血量公式**，后期关用大 radius 猪（r24~28 → hp2~3）+ 石/火壳包裹制造"两步杀"。
- 砰砰：爆炸半径/力**不变**；靠 W3 配队（每关 bomb 限额）+ stone hp6 + fire 抗爆，让它必须留给承重石/冻果、火砖则逼你换嘟嘟精准撞。
- 编辑器/自制关 v1 **不放火砖**（`editor.js` 物料枚举不动）；战役火砖不走 codec，`level-validate`/`level-sim` 的材料 HP/密度/统计 map 需认 fire。
- 批 B 落地后用 level-sim 实测微调这三个 hp（表中为起点值）。

### W2 — 难度量化器（新工具 `tools/level-sim.js`，先行的"尺子"）
复用 `tools/test-harness.js` + `tools/boss-sim.js` 的 aimBot/shoot：
- **静态指标**（扩 printMetrics 思路）：鸟/醒猪比、主材占比、加权方块血量、均猪 hp、裸露猪数（猪 r+6 内无方块）、bomb 数、冻果数——对照上表区间输出 PASS/WARN。
- **动态贪心模拟**：每关在当前鸟队列下，枚举 (鸟种 × 网格瞄准点) 各射一发，按 Δ(杀豚数×权重 + 碎块加权 + 王伤) 贪心选最优执行，直到 WIN/鸟尽；多轮取最优，报告**自动解用鸟数/配置鸟数**。
- 用途：① 死局报警（自动解用鸟数 > 配置鸟数 = 可能无解）；② 曲线验收（后期 用鸟数/配置鸟数 应趋近 1，即几乎不浪费）。

### W3 — 章节布局重做（`src/levels.js`，主体）
按上方曲线表逐章重排 35 个普通关（每关仍由 validate-levels 几何校验 + level-sim 动态验收）：
- 重排 = 调 `birds` 队列（压 bomb 数、压鸟数到资源比）+ 调 blocks 材料配比（主材≥65%）+ 猪（壳包裹/大猪/位置）+ 几何（挡平射墙/双结构/深埋）。
- **保留并同步**的既有断言：L16 split 教学冰锚点（`tools/e2e-tests.js:193-198`）、L19 石块数=2（:183）；重排这两关时一起改断言。
- 章王关（idx 7/15/23/31/39）布局不动，仅复验。

### W4 — 回归门 + e2e 难度断言（`tools/e2e-tests.js`）
- 新增：材料血量 sanity（wood3/ice2/stone6 下克制结果）；遍历 40 关断言鸟/醒猪比落各章区间、主材占比≥阈值、第四章起存在"壳包裹猪"（非全裸）。
- 死局回归：level-sim 全关自动解用鸟数 ≤ 配置鸟数；boss-sim 5 关 WIN。
- `overview.md` 加 T10 记录。
