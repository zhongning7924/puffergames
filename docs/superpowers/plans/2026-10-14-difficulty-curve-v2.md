# 难度曲线重构 v2（冲吧！小河豚）——五维压强预算 + 章内三幕节律

> 日期：2026-10-14 · 策划：阿关 · 状态：**待评审**
> 本方案为全新难度模型，不复用旧资源比曲线；旧曲线仅在审计一节作为对照出现。
> 红线不变：**每关必可通关（永不死局）**。

---

## 0. 一句话结论

把「关卡难度」从单一资源比（鸟/猪）升级为**五维压强预算**模型；曲线形态从「分章单调爬坡」改为**「章内三幕波浪（课-练-考-王）+ 章际峰谷双递增」**；并用「决策原型指纹唯一率」硬指标消灭换皮关。

---

## 1. 设计哲学（三根支柱）

| # | 支柱 | 含义 |
|---|---|---|
| P-A | **难度是五个数，不是一个数** | 弹药、识别、精度、序列、方差各自独立可测；任何单维曲线都会盲区 |
| P-B | **曲线要有呼吸** | 章内波浪制造「会-难-松-高潮」节奏防疲劳；章际峰谷双递增保证总体在涨 |
| P-C | **每一关必须教一个新决策** | 同章内决策原型不重复；换皮关（同解不同皮）视为设计缺陷 |

---

## 2. 为什么废弃「资源比」单一模型

资源比 `鸟数/醒猪数` 是难度的**代理指标**，不是难度本身，存在四个盲区：

| 盲区 | 失效场景（本作实例） |
|---|---|
| AoE 盲区 | 砰砰一爆清 3 豚 ≠ 3 发嘟嘟；资源比看不出「一发多用」 |
| 识别盲区 | 石堡三豚关资源比 0.75，但玩家真正的成本是「看出来只能用砰砰吊射」 |
| 精度盲区 | trajectory 提示 70 与 12 的两关，资源比相同、手感天壤之别 |
| 方差盲区 | 冻果连锁移位、落石漂移让同一关时易时难，资源比完全不可见 |

结论：保留资源比作为**五维之一**（P1 的输入），不再作为主轴。

---

## 3. 五维压强模型（每个数都可复算）

压强刻度统一为 **1~5，5 = 最压**。

| 维 | 名称 | 定义 | 复算公式 / 数据来源 |
|---|---|---|---|
| P1 | 弹药压强 | 最优解容错空间 | `P1 = 5 − W`；`W = 配置鸟数 − 最优解用鸟数`（level-sim 贪心自动解） |
| P2 | 识别压强 | 关卡要「读」出来的决策点数量 | `P2 = D`；`D = 承重柱数 + 克制错配目标数 + 机关触发点数 + 多段击杀目标数`（静态可数） |
| P3 | 精度压强 | 命中窗口窄度 | `P3 = clamp(round((70 − trajectory)/12), 1, 5)`（trajectory 为关卡弹道提示长度，70→12 单调） |
| P4 | 序列压强 | 发间依赖深度 | `P4 = L`；`L` = 最长依赖链深度：直射 1 / 塌压 2 / 连锁 3 / 多阶段章王 4~5 |
| P5 | 方差压强 | 结果不可控度 | `P5 = R`；`R = 暴露 burst 数 + 落石/援军漂移源数`；每关须附 worst-case 保底（贴脸果下限） |

**综合压强** `= mean(P1..P5)`（简单平均，透明可复算；权重留待数据验证后收敛）。

## 4. 章内三幕节律 + 章际双递增

每章 8 关固定四幕：

| 幕 | 关位 | 压强节奏 | 设计意图 |
|---|---|---|---|
| 课 | L+0 ~ L+2 | 本章低谷 | 新决策原型首次亮相，容错最大 |
| 练 | L+3 ~ L+5 | 中爬坡 | 原型应用三次，每次叠加一个变量 |
| 考 | L+6 | 本章次峰 | 本章原型压测 |
| 王 | L+7 | 本章尖峰 | 章王综合考（本章全部原型 +  Boss 机制） |

**章际硬规则**（可断言）：
1. **峰峰递增**：`peak(章N) > peak(章N-1)`
2. **谷谷递增**：`trough(章N) ≥ trough(章N-1)`
3. **章内波幅 ≤ 1.2**：`peak(章) − trough(章) ≤ 1.2`（第一章教学章允许顶格 1.2）

> 章间存在的 0.4~0.6「喘息落差」是刻意设计：防止五章连续高压导致流失，同时谷底仍高于上一章谷底，总体曲线只涨不跌。
