## 〇、命名依据（本轮修订的核心）

**软件全称：愤怒河豚的弹弓游戏软件　软件简称：愤怒河豚的弹弓**

定名同时满足两套规则：

| 规则来源 | 原文要求 | 本材料的符合情况 |
| --- | --- | --- |
| 中国版权保护中心《填表说明》 | 全称应简短明确、针对性强；参考「品牌 + 产品用途与功能 + 软件」；以**软件、系统、平台、插件、中间件**等结尾可以申请 | 全称以「软件」结尾，属列举内的规范写法 |
| 微信《小游戏资质提交审核指引》 | 「小游戏名称需与软著文件上的**全称或简称**保持一致，使用全称时，**可忽略游戏软件、版本号（如 V1.0）等后缀**」 | 全称去掉「游戏软件」与「V1.0.0」= 愤怒河豚的弹弓；且简称直接等于账号名，两条路径都能对上 |

因此微信后台名「愤怒河豚的弹弓」与本软著**无需任何后缀解释**即可通过资质比对：用全称走「可忽略游戏软件后缀」规则，用简称则完全一致。简称还便于日后申请版号时按简称登记。

> 先前版本曾用「愤怒河豚的弹弓小游戏」——「小游戏」不在版权中心列举的规范结尾内，也未在微信明示可忽略的后缀里，属灰区。已废弃。

## 五、后续步骤（网上申请）

1. 登录 register.ccopyright.com.cn，按 `申请表信息.pdf` 逐字段填写。两个已知坑：50 字字段超长会**静默截断**，先数好字数；编程语言列表默认收起，需点「展开更多」才有 JavaScript。
2. 全称填「愤怒河豚的弹弓游戏软件」，**简称务必填「愤怒河豚的弹弓」**（微信资质比对该简称，不要留空）。
3. 「主要功能及技术特点」直接粘贴 `config.json` 的 features（1,190 字，在 500–1300 区间内）。
4. 上传程序鉴别材料 `源代码.pdf`、文档鉴别材料 `操作手册.pdf`。文件选择框为系统对话框，需手动选。
5. 提交后打印签章页：手抄划线承诺文字（不能打勾代替）→ 自然人签字 + 手印或单位盖章 → 拍照 → 用 `img2pdf.py` 转 PDF 后上传。身份证明（营业执照/信用代码复印件）一并提交。

```bash
python3 ~/.workbuddy/skills/copyright-application/scripts/img2pdf.py 签章页1.jpg 签章页2.jpg 签章页.pdf
```

6. 微信侧提审时，在「账号设置 → 游戏设置 → 资质管理」提交软著证书；游戏名「愤怒河豚的弹弓」与简称一致，无需额外名称说明。

## 六、本次顺带修复的问题

1. **玩法说明卡片文字重叠**（项目侧）：`src/help.js` 中梭梭、砰砰、三丸子三条技能说明超过一行宽度，第二行与「克制」行叠字（真机同样出现）。已把三条文案压到单行（≤216px，单行上限 228px），界面不再重叠。改动后 e2e 123/123、关卡校验、静态难度模拟、预览构建与端到端验证全部通过。
2. **抽取脚本块注释未剥离**（技能侧）：`extract.py` 对 JS 只剥 `//`、不剥 `/* */`，首轮抽出 338 行注释残留。已补齐 `.js/.ts/.jsx/.mjs/.cjs/.java` 的 `block_comment`，重抽后残留为 0。
3. **操作手册缺页眉页脚**（技能侧）：手册 CSS 只有 `@page` 边距，Chrome 不实现 CSS 的页眉页脚盒，导致第 2 页起既无软件名称也无页码，不符合「鉴别材料需标注软件名称、版本号与页码」。已在 `to_pdf.py` 增加按 `<meta name="pdf-head">` 启用 Chrome 原生页眉页脚的通道（未声明时行为不变），手册 18 页现已全部带页眉与「第 N 页 / 共 18 页」。
4. **申请表「软件用途」被截断**（技能侧）：原实现取 features 前 80 字加省略号，用户直接抄进表单就是错的内容。已改为优先读 `software_usage`，否则取 features 首个完整句，不截断。
5. **申请表简称提示误导**（技能侧）：原提示为「无简称可留空」，会在需要靠简称对名的场景下误导。已改为说明「部分平台审核时按全称或简称比对产品名称，建议必填」；同时「主要功能及技术特点」一栏自动标注实际字数并在超出 500–1300 时告警。

## 七、复现方式

```bash
cd /Users/zhongning/games/angry-birds/copyright/愤怒河豚的弹弓游戏软件V1.0.0
PY=~/.workbuddy/binaries/python/envs/default/bin/python
S=~/.workbuddy/skills/copyright-application/scripts

$PY $S/extract.py       config.json
$PY $S/render_source.py config.json
$PY $S/make_form.py     config.json
$PY make_manual.py
$PY diagrams.py
$PY $S/to_pdf.py . 源代码.html 申请表信息.html 操作手册.html
```
